# Make_Note  
  
A simple Hybrid Note taking widget/plugin designed for Makehuman 2 as a proof of concept for testing purposes.   
  
Make_Note operates stand alone py or as a community style plugin with docking allowed in MH2. It is designed to respect  
the ui of mh2.  This is a work in progress.  This requires the plugin version of MH2 and up in order to be loaded  
within the mh2 software.

work with images of your inspiration at your bequest.
